- **For the developer:** `seed_basis` drops every card line that starts with the comment string, a wider rule than the header alone. Phase 2 says to reuse it, but a card line the user wrote that starts with a comment (a `[card].lines` entry) would then not move the key while it does move the identity, and two different cards would pool. Recommendation: strip the exact header only (one shared helper that matches the header's text; `seed_basis` left as it is, since changing it reruns nothing but is forbidden without an ask). The alternative is the wider rule, one rule and a risk of a false share.
